# Changelog

**Language:** [Português (Brasil)](../changelog.md) · English

## [0.1.4] — 2026-11-26

### Added

- The `browser-relay` skill is included in plugin installation, and new sessions
  now use the `opencode-browser` agent.
- The side panel and settings interface are refreshed, with improvements to
  accessibility, navigation and responsiveness.

### Fixed and improved

- Keyboard shortcuts now respect literal symbols without inferring the keyboard
  layout.
- The documentation distinguishes key events (`keyDown`/`keyUp`) from text
  insertion (`type`).
