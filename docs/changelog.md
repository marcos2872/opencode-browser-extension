# Histórico de versões

**Idioma:** Português (Brasil) · [English](en/changelog.md)

## [0.1.4] — 2026-11-26

### Adicionado

- Skill `browser-relay` integrada à instalação do plugin; novas sessões passam a
  usar o agente `opencode-browser`.
- Interface do painel e das configurações modernizada, com melhorias de
  acessibilidade, navegação e responsividade.

### Corrigido e melhorado

- Atalhos passam a respeitar símbolos literais sem inferir o layout do teclado.
- A documentação distingue eventos de tecla (`keyDown`/`keyUp`) da inserção de
  texto (`type`).
