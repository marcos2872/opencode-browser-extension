Conexão

Campo / botãoPara que serve
Link do opencode pair + ConectarAparece só quando não há pareamento; cola o link e conecta
ServidorMostra o endereço, só leitura
TokenMostra os primeiros e últimos caracteres, só leitura
Abrir painelAbre o painel lateral na janela atual
ReconectarReconecta à API do OpenCode
Reconectar pluginReconecta ao plugin das ferramentas
DesconectarRemove o token (pede confirmação)

Duas linhas de status: API: (online, conectando, não configurada ou o motivo do offline) e Ferramentas: (estado do plugin).
