5. Getting to know the screen

The panel has five regions:

RegionWhat it holds
HeaderThe “OpenCode” brand, the conversation title, the API status dot (online/offline/connecting) and the Settings button
Conversation barConversation picker, agent picker, tabs button, + (new conversation) and delete
ChatMessages, model reasoning, tool cards and permission requests
ComposerText field, / command menu, Send/Stop button and the footer with context and cost
NoticesConnection banner, status strip, permission cards and temporary notices (toasts)

Shortcuts

KeyWhereEffect

Shift+EnterComposerBreaks the line without sending

EscTools modalCloses the modal
Ctrl+Shift+O / Cmd+Shift+OOn any tabOpens the panel

The composer has no “stop” shortcut: to interrupt, use the Stop button (the same icon appears on the page, inside the agent indicator).

6. Your first conversation

  1. Type in the “Ask OpenCode something...” field and press Enter.
  2. The reply appears as a stream; while the agent works, the field shows “The agent is working...”.
  3. When it uses a tool, cards appear (see section 7).
  4. If it needs permission, the card appears over the panel (section 10).

The empty screen offers four ready-made suggestions:

  • “Open Hacker News and summarize today's top 5 stories.”
  • “Read the current page, find the contact form and fill it with test data.”
  • “Investigate the console errors and network requests on this page.”
  • “Look up the price of a product in three stores and compare them in a table.”

Slash commands

Type / (with no space after it) to open the command menu. The list comes from your OpenCode and shows up to 6 suggestions; choosing one completes the field with /name . After choosing, write the rest and send — for example /review fix the diff.

If you send /name and nothing else, the command runs without arguments.

Draft per conversation

The text you typed is kept per conversation. Switching conversations and coming back does not erase what was written. If you type before any conversation exists, the text goes with the conversation that gets created.

Context and cost

The composer footer shows, when available:

  • “Context 1,234 (12%)” — tokens from the last request and how much of the model window they take;
  • “Session US$ 0.0000” — cost reported by OpenCode.

Without that data, the footer shows the hint “Enter sends · Shift+Enter breaks the line”.

Stopping a run

The Stop button in the composer interrupts the conversation on screen. Each conversation has its own button: stopping one does not affect the others.

11. When the agent asks a question

Besides permissions, the agent may ask for an answer from you — a choice, a number, a yes/no. That appears as a card in the chat, with the question title and the status “waiting”.

The possible fields are: free text, number, yes/no, single choice, multiple choice (with the “Other answer” option) and external link. Required fields must be filled in to enable the button.

  • Answer — sends your answer and the agent continues;
  • Cancel — ends the question without an answer (no confirmation).

With the panel closed, a notification arrives: “The agent needs an answer: …”.
