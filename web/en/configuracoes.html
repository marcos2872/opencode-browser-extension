Settings

12. Settings

Open them with the Settings button in the panel header.

Language

OptionEffect
Automatic (browser language) (default)Portuguese when the browser is in Portuguese; English in any other language
Português (Brasil)Panel, settings, on-page indicator, notifications and manifest in Portuguese
EnglishThe same texts in English

The change is immediate and applies to every extension window. Agent replies are not translated: they follow the language of the message you write.

Connection

Field / buttonWhat it is for
opencode pair link + ConnectOnly appears when there is no pairing; paste the link and connect
ServerShows the address, read-only
TokenShows the first and last characters, read-only
Open panelOpens the side panel in the current window
ReconnectReconnects to the OpenCode API
Reconnect pluginReconnects to the tools plugin
DisconnectRemoves the token (asks for confirmation)

Two status lines: API: (online, connecting, not configured or the reason for being offline) and Tools: (plugin state).
