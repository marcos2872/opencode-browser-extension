User guide — OpenCode Browser

This guide walks through every feature of the extension, in the order you will meet each one: install, connect, chat, let the agent work in the browser, approve permissions, run several conversations at once and adjust the settings.

OpenCode Browser is a Chrome side panel that talks to OpenCode Terminal running on your machine. The agent reads pages, clicks, fills in forms and navigates inside a tab group isolated per conversation — and every action that changes something asks for your permission (or does not, depending on the chosen mode).

Nothing leaves your computer: the extension talks to 127.0.0.1, and the plugin that gives the agent its tools only listens on loopback.
